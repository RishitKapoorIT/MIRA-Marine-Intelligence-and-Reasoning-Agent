# ORCA — Marine Intelligence Web Application
**Frames 01–10 Complete Implementation**

Please see the root repository documentation in [`Readme.md`](../Readme.md) for full architectural specifications, data provider lineages, and multi-agent pipeline documentation.

### Quick Start
```bash
# Start Vite Development Server
npm install
npm run dev

# Production Build
npm run build
```

The frontend connects to the self-hosted PFZ FastAPI backend running on `http://localhost:8000` via `VITE_PFZ_API_BASE`.
